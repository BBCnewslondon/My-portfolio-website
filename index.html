Black-Hole Ray Tracer

General Relativity RK4 Python

Problem

Visualising how photons travel near a Schwarzschild black hole requires solving the geodesic equations in curved spacetime. Unlike flat-space ray tracing, light follows null geodesics — the shortest paths through curved geometry — producing phenomena like photon rings and gravitational lensing that have no Euclidean analogue.

Approach

Implemented a 4th-order Runge-Kutta integrator for the null geodesic equation in Schwarzschild coordinates. Each photon trajectory is parametrised by an affine parameter λ:

$$\frac{d^2 x^\mu}{d\lambda^2} + \Gamma^\mu_{\alpha\beta}\frac{dx^\alpha}{d\lambda}\frac{dx^\beta}{d\lambda} = 0$$

where the Christoffel symbols $\Gamma^\mu_{\alpha\beta}$ encode the curvature of the Schwarzschild metric:

$$ds^2 = -\!\left(1-\frac{2M}{r}\right)dt^2 + \left(1-\frac{2M}{r}\right)^{\!-1}dr^2 + r^2\,d\Omega^2$$

Analogy: Think of spacetime near a black hole as a funnel-shaped rubber sheet. A marble (photon) rolled across the surface curves inward — the steeper the funnel (stronger gravity), the more extreme the bending. The geodesic equation computes exactly how much that marble curves at every point.

Result

Produced photon ring images consistent with reference trajectories. The RK4 integrator maintained stable orbits at the critical impact parameter $b = 3\sqrt{3}\,M$, reproducing the expected photon sphere structure.

Gravitational N-Body Simulation

Classical Mechanics Verlet Integration Python

Problem

The gravitational N-body problem — predicting the future positions of $N$ mutually attracting masses — has no general closed-form solution for $N \geq 3$. Brute-force pairwise force computation scales as $O(N^2)$, and naïve Euler integration introduces artificial energy drift that corrupts long-term orbital dynamics.

Approach

Chose the velocity Verlet scheme — a symplectic integrator that exactly preserves the phase-space structure of Hamiltonian systems, preventing secular energy drift:

$$\mathbf{r}(t+\Delta t) = \mathbf{r}(t) + \mathbf{v}(t)\,\Delta t + \tfrac{1}{2}\mathbf{a}(t)\,\Delta t^2$$
$$\mathbf{v}(t+\Delta t) = \mathbf{v}(t) + \tfrac{1}{2}\bigl[\mathbf{a}(t)+\mathbf{a}(t+\Delta t)\bigr]\Delta t$$

The gravitational acceleration on each body is computed from the pairwise sum:

$$\mathbf{a}_i = \sum_{j\neq i}\frac{G\,m_j}{|\mathbf{r}_j - \mathbf{r}_i|^3}(\mathbf{r}_j - \mathbf{r}_i)$$

Analogy: Standard Euler integration is like estimating a road trip with only one speed reading per hour — errors accumulate. Verlet integration reads the speedometer at the start and end of each interval and averages, keeping the running total of distance (energy) consistent over long journeys.

Result

Stable long-term evolution for systems up to $N = 1000$ bodies. Total energy conservation verified with relative drift $|\Delta E / E_0| < 10^{-8}$ over $10^4$ time steps, consistent with the expected symplectic bound.

Physics-Informed Neural Networks

PINNs PDEs PyTorch

Problem

Traditional PDE solvers (finite-element, finite-difference) require explicit mesh generation that becomes costly in high dimensions or complex geometries. PINNs offer a mesh-free alternative by embedding the governing PDE directly into the neural-network loss function. The challenge is balancing data fidelity with physics constraints during training.

Approach

Built a PINN architecture (Raissi et al., 2019) where the loss function combines boundary/initial-condition data with a PDE residual term:

$$\mathcal{L} = \underbrace{\frac{1}{N_d}\sum_{i=1}^{N_d}\bigl|u_\theta(x_i)-u_i^*\bigr|^2}_{\text{data loss}} + \;\lambda\underbrace{\frac{1}{N_r}\sum_{j=1}^{N_r}\bigl|\mathcal{N}[u_\theta](x_j,t_j)\bigr|^2}_{\text{PDE residual}}$$

where $\mathcal{N}[u_\theta]$ is the differential operator applied to the network output, evaluated via automatic differentiation. The weight $\lambda$ balances data fidelity against physics compliance.

Analogy: Imagine training a student with two textbooks: one contains answer keys (data), the other states the rules of physics (PDE). PINNs make the student satisfy both simultaneously — predictions must match observations and obey physical law.

Result

Solutions validated against analytical benchmarks for canonical PDEs. The trained network achieved residual convergence $\|\mathcal{L}_{\text{PDE}}\| \to 0$ with no mesh generation required, demonstrating viability for problems where traditional solvers face geometric complexity.
